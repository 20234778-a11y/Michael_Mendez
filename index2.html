GUÍA PRÁCTICA PASO A PASO

Cómo lanzar tu web a GitHub Pages hoy mismo

Sigue esta guía directa para tener tu proyecto en vivo en menos de cinco minutos.

1

Estructura tus archivos

Coloca tus tres archivos principales en la carpeta de tu proyecto (mi_pagina_web): index.html, style.css y script.js. Asegúrate de que el archivo HTML esté nombrado en minúsculas y sin acentos.

2

Sube tu repositorio a GitHub

Inicia sesión en GitHub, crea un repositorio nuevo llamado mi_pagina_web en modo Público. Usa la opción Upload files para arrastrar tus archivos y haz clic en Commit changes.

3

Activa GitHub Pages

Ve a la pestaña Settings ➔ Pages. En la sección Build and deployment, elige la rama main y la carpeta /(root). Haz clic en Save.

4

¡Tu producto está en vivo!

Espera un par de minutos, refresca la página de Settings y obtendrás tu URL pública con candado SSL:
https://tuusuario.github.io/tu-producto
